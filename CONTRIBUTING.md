# Contributing to Skill Installer

Thank you for your interest in improving Skill Installer! We welcome contributions from developers, security researchers, and AI agent engineers.

## How to Contribute

1. **Fork the Repository** on GitHub.
2. **Create a Feature Branch** (`git checkout -b feature/amazing-feature`).
3. **Write Tests or Heuristics** for new security checks or backup adapters.
4. **Commit your changes** (`git commit -m 'feat: add S3 backup adapter'`).
5. **Push to the Branch** (`git push origin feature/amazing-feature`).
6. **Open a Pull Request**.

## Focus Areas
- **Alternative Detection:** Enhancing keyword/semantic models to better detect skill overlap.
- **Security Heuristics:** Adding new static and YARA rules to catch malicious prompt injections and exfiltration techniques.
- **Cloud Adapters:** Adding native support for AWS S3, Cloudflare R2, and Azure Blob storage backups.
